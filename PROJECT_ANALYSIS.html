五、发现的问题与风险（2026-09-12 已全部修复 ✅）

✅ 已修复 一致性 版本号不一致
原状：__init__.py=3.7、utils/version.py=3.7.1、README=3.8.0 三处不一致。现全部统一为 3.8.0（含 setup.py 回退值与测试断言，共 5 处）。
✅ 已修复 运行 JupyterLab 启动超时（根因：管道阻塞）
根因：subprocess.Popen(stdout=PIPE) 无线程排空，JupyterLab 启动日志写满 ~64KB 管道缓冲后子进程阻塞，服务器永远无法就绪。修复：新增守护线程持续排空输出（环形缓冲 200 行），超时/崩溃时自动转储最近 30 行输出辅助诊断，等待期间每 10 秒输出进度日志，默认超时 30s→45s。
✅ 已修复 运行 打包后样式表缺失
根因：PyInstaller 6.x ONEDIR 布局下资源位于 _internal/mathlab/，而代码按旧布局查找。修复：main.py 新增 _find_resource()，按 _MEIPASS→exe 目录→源码目录三级探测，同时修复图标路径。
✅ 已确认修复 安全 Bandit 3 项告警（原报告过期）
复核发现代码中此前已修复（MD5 带 usedforsecurity=False、两处 urlopen 均有 scheme/主机校验 + # nosec B310）。用 bandit 1.9.4 以 CI 同参数重扫：0 问题，bandit-report.json 已重新生成。
提示 构建产物占盘
仓库根目录含 dist/(2,875 文件)、build/、venv/ 等大量构建/环境产物。若为源码仓库请确保 .gitignore 已排除，避免误提交。
待办 spec 平台覆盖不完整
mathlab.spec 仅生成 Windows EXE 与 macOS BUNDLE，README 提及的 Linux AppImage 无对应构建目标，跨平台发布需补充。
